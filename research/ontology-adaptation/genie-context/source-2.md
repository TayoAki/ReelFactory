## Genie Code FAQ

Expand All

What is Genie Code?

Genie Code is an AI agent for data teams that autonomously plans, executes and maintains complex data workflows inside the Databricks Data + AI Platform. It handles multistep tasks across data science, data engineering, machine learning and BI dashboards without requiring users to switch contexts or write manual code.

How is Genie Code different from a general-purpose AI agent?

Unlike general-purpose AI agents such as Claude Code or Cursor, Genie Code is purpose-built for data work. It’s grounded in Unity Catalog metadata and governance, meaning it automatically selects authoritative data, understands dependencies across your data and AI assets, and operates within your existing security model. It’s data-smart by design, not by prompt.

What data workflows can Genie Code automate?

Genie Code supports four primary workflow categories: exploratory data analysis and reporting (data science), feature engineering, model training and endpoint deployment (machine learning), ETL pipeline building and optimization (data engineering), and dataset creation with dashboard generation (business intelligence). It can plan and run multistep tasks end to end across all four.

How does Genie Code use Unity Catalog?

Genie Code is grounded in Unity Catalog, the Databricks unified governance layer. When you describe a task, Genie Code queries Unity Catalog to surface the most relevant and authoritative tables, metrics and assets, automatically respecting access controls and data classifications. This means the agent operates on trusted data without requiring manual table lookups or governance overrides.

Can Genie Code build and monitor production pipelines?

Yes. Genie Code can build production-ready Spark Declarative Pipelines through natural language, automate ETL workloads, optimize queries and proactively monitor running pipelines. When issues arise, it can diagnose and resolve them autonomously, helping data engineering teams maintain uptime without manual intervention.

Does Genie Code work with MCP tools and external systems?

Yes. Genie Code supports MCP (Model Context Protocol), which allows teams to securely expose external tools, data sources and workflows so Genie Code can retrieve context when executing tasks. Teams can also define custom Databricks Agent Skills, which package domain-specific best practices and reusable code that Genie Code loads to execute specific workflows.

What is the difference between Genie Code and Genie Agents?

Genie Code is an autonomous AI agent for technical data teams — data engineers, data scientists and ML engineers — who build and maintain data and AI systems. Genie Agents is a conversational analytics interface designed for business users who want to query and explore data through natural language without writing code. Both are part of the Databricks Genie product suite.
