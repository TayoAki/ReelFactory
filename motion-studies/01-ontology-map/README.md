# Motion study 01 — opening ontology map

Reconstructs the 8.000–15.267s graphic from the user-supplied reference. Editable native SVG boxes, paths, text, icon groups and shared camera; no source video is used inside the reconstructed animation. Source video is used only in the comparison player.

Camera bounds were measured from the main card at multiple times; intermediate motion uses monotone cubic interpolation. Reveal timings are fitted from inspected frames. The Genie lamp is a hand-drawn vector approximation and the font is Liberation Sans (Arial-metric compatible); neither is claimed to be the original source asset. Four generic icons are Font Awesome Free 6.x (CC BY 4.0 icons), downloaded from https://github.com/FortAwesome/Font-Awesome. Original source captions and creator mark are excluded from the graphic-only comparison.

This is a first matching study, not a completed exact replica and not the Fabric adaptation. Timing and camera samples: timing.json.
