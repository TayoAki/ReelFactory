Your Power BI semantic model can also be a source for a Fabric data agent.

Microsoft's documented setup starts by creating the agent and choosing its data sources.

You can add up to five supported sources in one agent.

Select the tables it should use. Give columns and tables descriptive names.

Then ask a concrete question. For example, what were total sales in California in twenty twenty three?

The agent can generate SQL, DAX or KQL, depending on the data source.

It uses your data access permissions. Clear descriptions and a clean model help it choose the right query.

Before a real demo, check capacity prerequisites, permissions, and the generated query against a known answer.
